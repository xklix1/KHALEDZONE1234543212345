# KHALED ZONE - Digital Gaming Marketplace

High-performance, RTL-native digital gaming services and account marketplace built with responsive HTML5, Tailwind CSS, and modular JavaScript architecture.

## Architecture Highlights
- **Multi-page Routing**: Clean URLs without `.html` extensions (`/store`, `/offers`, `/services`, `/about`, `/contact`, `/product`).
- **State Management**: Unified `localStorage` cart state persistence across all pages.
- **Design System**: Custom glassmorphism, high-contrast dark theme, neon blue (`#00f0ff`) and gold accents.
- **Checkout Pipeline**: Instant WhatsApp cart summary integration.

# Start local development server
